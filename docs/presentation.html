Problem

  • Maintenance must block unavailable machines
  • High-priority jobs should win when conflict occurs
  • Transport time between sites must be respected

Solution

  • FastAPI backend with SQLAlchemy persistence
  • React frontend for operational workflow
  • Google OR-Tools CP-SAT for conflict resolution
  • Shift-aware scheduling logic for morning/afternoon/full-day bookings

Testing and AI Loop

  • Verified final behavior with the backend test suite
